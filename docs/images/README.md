# README用の写真

[READMEへ戻る](../../README.md)

## 用意する3枚

| 保存名 | 内容・撮り方 | READMEの位置 |
|---|---|---|
| `hero.jpg` | カメラ・LEDリング・操作端末が分かる装置全体。背景を整理し、横長で撮影 | 作品紹介の直後 |
| `demo.jpg` | 飲料を飲んでいる人と装置を横から撮影。カメラの位置と使い方が伝わる構図 | デモの体験手順の直後 |
| `web-ui.png` | ライブ映像と判定結果が同時に分かる画面。スマートフォン表示でもPC表示でも可 | デモ写真の次 |

写真は横幅1,600px前後、1枚あたり1MB程度を目安にしてください。画面は文字が読める解像度を優先します。ファイル名は小文字でそろえてください。

## 追加方法

1. 公開する画像だけをこのディレクトリに保存します。
2. ルートの`README.md`で、対応する`PHOTO`コメントを探します。
3. 中にある画像のMarkdown行をコメントの外へ出します。コメントブロック全体をその画像行で置き換えても構いません。
4. Markdownプレビューで画像と文字の読みやすさを確認します。

例えば装置写真は、ルートのREADMEに次の1行を表示します。

```markdown
![Delicious Detectorの装置全体。カメラ、LEDリング、操作端末](docs/images/hero.jpg)
```

写真がまだない場合はコメントのままで構いません。

## 余裕があれば追加する写真

- `led-water.jpg`：水の判定時に青く光るリング。
- `led-sparkling.jpg`：炭酸水の判定時に赤く光るリング。
- `hardware.jpg`：カメラとリング、Piの配置が分かる写真。

LEDの比較写真は同じ角度・明るさで撮り、デモの節へ並べると結果が伝わります。

## 公開する画像の確認

- 写っている人の公開同意を得てください。実験参加者の記録画像をそのまま流用せず、公開用に撮影したものを使用します。
- 氏名、参加者ID、履歴、通知、Wi-Fi情報、個人ファイルのパスなどの写り込みを取り除きます。
- GPS位置情報などのEXIFメタデータを削除した書き出し画像を使います。
- 未加工の原本や実験用の連続画像はこのフォルダに入れないでください。

このフォルダ内のJPG / JPEG / PNG / WebPはGitへ追加できます。その他の場所の写真と、動画・実験データは`.gitignore`で除外します。
